# trajectories.json schema

Top level: `{meta, worlds, rows}`. Generated by `viz_export.py`; nothing is exported unless every reproduction check matches.

## meta
- `generated` — ISO timestamp of the export.
- `generator` — absolute path of viz_export.py.
- `src` — repository source folder the modules were imported from (unchanged).
- `values` — value supplied to the agents: valued odour +1, neutral 0.
- `odour_codes` — A = channel 0, B = channel 1 (ph16 CELLS naming).
- `step_semantics` — timing of per-step fields (see below).
- `reproduction` — lines of the reproduction check (bitwise identities and recorded counts), same as repro_check.txt.
- `reproduction_ok` — true if every check matched.

## worlds.{T1, W1, T3}
- `description` — which world class and what is masked.
- `seeds` — [world seed, agent seed] of the recorded run.
- `arms` — arm name -> agent class and settings.
- `arena` — x and y bounds [0, 160], reflecting walls.
- `LMAX` — cone length 25.
- `cone` — cone membership formula (d_along = x - x_src, d_cross = y - y_src).
- `at_source_emits` — whiffs also occur within 3.0 of a source.
- `whiff_p` — per-step Bernoulli probability 0.30·exp(−max(d_along,0)/12).
- `HIT_R` — 3.0, radius for at_source / dwell / reach.
- `SEP`, `DOWN` — source separation (10, crosswind) and start distance (20, downwind).
- `coordinate_convention` — wind toward +x; upwind = heading 180 = −x; heading 90 = +y; sources at x = x0, start at x0 + 20.
- `speed` 0.6, `UPWIND_deg` 180, `RESET_AFTER` 40, `CAST_PERIOD` 30, `MAXOFF` 170, `steps` 600, `rows_in_run` 400.
- `t0` (T3 only) — step from which the valued odour is masked (150); `N_WIN_agent9` — Agent9 presence window (Agent9 reproduced, not exported).

## rows[]
- `world` — T1, W1 or T3.
- `row` — row index within the 400-row run (same world across all arms of the row).
- `seeds` — {world, agent} seeds.
- `valued_odour` — A or B (the valued odour's channel).
- `valued_side` — +y or −y: side of the valued source relative to the other.
- `cast_sign_initial` — initial cast side (+1/−1) drawn from agent seed + 20000.
- `valued_source`, `neutral_source` — [x, y] of each source (W1/T3: the valued source is silenced, entirely in W1, from t0 in T3).
- `start` — [x, y] of the agent before step 0.
- `selection` — `{criterion, values}`: why the row was chosen and the criterion values per arm.
- `arms.<arm>` — per-arm data for this row:
  - `outcome` — T1: `class` V/N/tie by dwell majority. W1: `reach`, `dwell`, `first_reach_step`, `final_d_along` for the present (neutral) source. T3: `eligible`, `L` (last valued whiff before t0), `held_at_600`, `S_neutral_surge_L1_L100`, `dwell_neutral_400_599`.
  - `first_hold` — {odour: valued|neutral, step} of the first step anything is held, or null.
  - `first_valued_whiff_step`, `first_neutral_whiff_step` — first step with that whiff, or null.
  - `revision_step` — first step holding valued after an earlier neutral hold, or null.
  - `dwell_valued`, `dwell_neutral` — steps within HIT_R of each source over 600 steps.
  - `steps[]` — 600 per-step records:
    - `step` — 0..599.
    - `x`, `y` — position after this step's move (2 dp).
    - `heading_deg` — heading after this step's move, degrees, 0 = +x (2 dp).
    - `held` — valued | neutral | none: odour held by the selection circuit this step (known-answer: fixed to valued).
    - `whiff_valued`, `whiff_neutral` — whiff sensed this step (at the position before the move).
    - `nav` — surge signal this step (target = upwind).
    - `since` — cast clock: steps since the last nav.
    - `s_valued`, `s_neutral` — selection circuit unit states (3 dp); held means s > 1 in exactly one unit.
    - `S` — circuit pool (inhibitory) state (3 dp).
    - `target_deg` — navigation target heading this step (2 dp).
    - `at_valued`, `at_neutral` — within HIT_R of that source after the move.
