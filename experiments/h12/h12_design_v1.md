## 1. Hypothesis

**H12 (as it could be run): in the adopted learning module with its extinction written at the separate parallel site, and that site alone relaxing back toward its initial weight with one registered time constant, (i) every Phase 4 property and the gate's sustained-exposure property are kept; (ii) after acquisition then extinction, the extinguished memory recovers over a retention interval without any input (spontaneous recovery) for BOTH valence signs, while an acquired memory never extinguished is retained over the same interval; a single-site layout with any decay applied to its compartments cannot show (ii) for both signs (section 2.2).** Stage 2 (section 5) would then ask whether that recovery reaches behaviour in Agent17 with learning on.

What "the acquisition trace" and "the extinction trace" are, in the code (**read**):

- **The acquisition trace** is the depression of the weights w[c, k] of the compartment whose reinforcement unit was active, on the units k of the odour's sparse code: dw = -eta_d x reinf_c x tc_now (ph4.py:58, ph8.py:94). Compartment 0 is the punishment compartment and compartment 1 the reward compartment; behavioural valence = (out0 - out1) + (out2 - out3) (ph8.py:63-65), outc the mean weight of compartment c over the code's active units (ph4.py:37-39). Punishment paired with an odour depresses w[0] on its units and the valence falls; reward depresses w[1] and it rises. Weights are clipped to [0, 2] (ph4.py:60), so a saturated memory has its acquisition weights at the floor 0 (Stage B: the learned value exactly +1.0 in 400/400 rows, **measured**).
- **The extinction trace** is written by the opponent feedback: on a step with an odour code, the behavioural valence drives a reinforcement signal of size beta x max(valence, 0) or beta x max(-valence, 0) (ph8.py:74-91), which then depresses weights by the same rule. In the adopted layout (parallel False) the drive of an appetitive memory depresses w[0] and that of an aversive memory depresses w[1] (ph8.py:88-90): **extinction is already written on a different compartment from the one acquisition wrote, but that compartment is the acquisition site of the opposite valence.** In the parallel layout the drive writes compartments 2 and 3 (ph8.py:85-87), which no reinforcement ever addresses. The drive reads the behavioural valence, so extinction is self-limiting: it approaches valence 0 and never crosses it (ph8.py:51-53 docstring, :76, :82-83).
- **The gate:** the feedback is multiplied by 1 only on steps on which no external reinforcement arrives on any compartment, gate = (reinf.sum <= 0) (ph8.py:78-81), so extinction answers the omission of the outcome, not the expectation (decision:phase7-2-gate).
- **The eligibility traces are not memory.** tc (code) and tr (reinforcement) decay with tau 5 steps (ph4.py:61-63); they carry the timing sign. The 'traces' of H15 Run 2's interference finding (two odours trained back to back: +-2.0 second-trained against +-0.5 first-trained, unless 50 silent steps separate them; ph15.py:141-146, GAP 50 at :138) are these eligibility traces, not the two memory sites of H12.
- **The parallel site, as implemented and held unproven:** MB4(parallel=True) exists since Phase 7.2 (ph8.py:40-99); the adopted agent constructs MB4 with C 4 and parallel False (ph11.py:53, :115), so compartments 2 and 3 are allocated, never written, and contribute out2 - out3 = 0 to every valence the agent reads. Held unproven by decision:phase7-2-gate: it changed no behaviour in any protocol tested.

**What 'persist differently' means as a measurable claim.** After acquisition then extinction, the acquisition memory is retained while the extinction memory decays, so that without further input the behavioural valence returns toward the acquired value over time (spontaneous recovery), and a re-test after a delay finds more of the original memory than was expressed at the end of extinction. Renewal (recovery on a change of context) cannot be expressed: the module has no context input (section 11). Reacquisition savings in the fly sense (faster relearning by re-pairing) cannot be produced by decay alone in this module (section 2.2, last point).

**The fly grounding, RECALLED, not verified in this session, no number used:** in Drosophila, extinction of an olfactory memory has been described as new learning that runs in parallel with the original memory in the mushroom body, written by dopaminergic neurons of the opposite valence at other compartments, so that the two memories coexist and are integrated at the output neurons (Felsenberg et al. 2017, Nature, 're-evaluation of learned information'; Felsenberg et al. 2018, Cell, 'integration of parallel opposing memories underlies memory extinction', the reference ph8.py:12 cites); extinguished olfactory memories in flies have been reported to recover over time (spontaneous recovery; recalled from the fly extinction literature, for example Schwaerzel, Heisenberg and Zars 2002, Neuron, and Qin and Dubnau 2010; which of them reports it, and at what delays, is NOT verified here). In classical conditioning generally, spontaneous recovery, renewal, reinstatement and faster reacquisition after extinction are the standard evidence that extinction does not erase the original memory (Pavlov; Bouton 2004 and Rescorla 2004 as reviews; Napier, Macrae and Kehoe 1992 for rapid reacquisition; all recalled). None of this is claimed for the model; it names what the model's property would correspond to.

**What would distinguish the two accounts in this project.** At the module level: sign-symmetric spontaneous recovery with an acquisition memory retained over the same interval (section 2.2 shows the single-site layout cannot produce it with any per-compartment decay). At the behavioural level: an agent whose valued odour's reward is withdrawn until it stops choosing it, then kept away from that odour for a retention interval, returns to it when it is met again only if its value recovered (section 5); this requires a world in which a value change is expressed in behaviour, which the adopted read-out does only at a crossing (section 2.3).

## 2. The measured reason

### 2.1 Honestly: no measured failure calls for H12

- The queue ranked H12 third after H28 and the T3b limit: 'the memory half of the core, but no measured failure calls for it' (decision:h28-open-design, decision:h29-open-design; master_plan.md queue). That stays true: no behaving run on record has shown a cost of the module's lack of persistence, because (2.3) no behaving run on record has ever exercised extinction with the gate on.
- The reasons it is designed now are three, none a measured failure: (1) the order the owner confirmed twice (decision:h28-open point 10; decision:h29-open point 9); (2) the module boundary outlook (notes/module_boundary_outlook.md, doc d8dbff6b70830a8c5): the reusable part of the agent is 'how the agent recognises a value when it arrives and how it remembers it', and its section 2.3 lists for the long memory 'no reacquisition savings (0.0x in every cell, a model with no decay)' and 'a parallel storage site preserves a trace that is behaviourally inert'; (3) Stage C (decision:h20-stage-c-run2-closed) is the first record of values changing during behaviour (a punisher value of -0.889 [-0.894, -0.800] learned from one visit with learning on), which makes 'what survives extinction' an operational question for the adopted agent: after a value is learned and its plume left, does it decay; if the odour is met unreinforced later, does the memory persist or extinguish; after a reward stops, does the positive memory extinguish and can it come back.

### 2.2 Why the parallel site is inert, and what would make it earn its place (read, measured, inferred)

- **Measured (H11):** the two-by-two at K 500, 200 runs per cell: F1 (the Phase 4 battery: acquisition 200/200, dA -0.727, leakage 4.0 percent, extinction to 22 percent of trained, reversal 200/200, timing sign 200/200) identical in all four cells; F2 (sustained pairing) retains 0.3 percent ungated, 100.0 percent gated; F3 (acquisition-site valence after extinction) 22 percent kept in the single-site cells, 99 percent in the parallel cells; F6 (one re-pairing after extinction, added after the run): trained -0.727, extinguished -0.158, after one re-pairing -0.161, naive after one pairing -0.110, savings 0.0x, identical to three decimals in every cell.
- **Why identical (read, exact):** extinction of an aversive memory writes w[1] (single site) or w[3] (parallel) by the same amount on the same units, and the valence is the linear sum (out0 - out1) + (out2 - out3) with out2 = 1 untouched, so the two layouts give the same valence at every step. They differ only in which weights hold the opposing trace, which nothing reads separately.
- **Why re-pairing does nothing (read, inferred):** the acquisition weights are at their floor after training (F3's acquisition site -0.997 in the parallel cells, measured; the clip at ph4.py:60), so another reinforcement cannot depress them further; and each forward re-pairing presents the code for 5 steps before the reinforcement (ph4.py:70-83), with the gate open on those steps, so the re-pairing writes MORE extinction. With no decay the opposing trace is permanent (Phase 7.2 report: 'This model has no decay of any kind').
- **What a single site can and cannot do with persistence (inferred from the code, exact up to the clip):** in the single-site layout, compartment 1 holds both an aversive memory's extinction trace and an appetitive memory's acquisition trace, and compartment 0 the reverse. (S1) One decay rate on every compartment relaxes both the acquisition and the extinction deviations by the same factor f = (1 - 1/tau)^D over D silent steps, so the valence is multiplied by f: it only fades, it never recovers. (S2) Different rates per compartment (say compartment 1 decaying, 0 not) give recovery of an aversive memory (its extinction trace in w[1] decays) but make every appetitive memory transient (its acquisition trace is in w[1]), and an extinguished appetitive memory then inverts sign over time (its extinction trace in w[0] stays while its acquisition fades). **No assignment of per-compartment rates in the single-site layout gives recovery for both signs with retained acquisition.** In the parallel layout the extinction pair (2, 3) holds only extinction traces of either sign, so one decay on that pair and none on (0, 1) gives both. That is the precise sense in which 'differential persistence is what would make the parallel site earn its place'.
- **What decay alone does not give (inferred):** reacquisition by re-pairing. With the acquisition weights at the floor and the gate closing extinction only while reinforcement arrives, a re-pairing after a retention interval still cannot restore the value; the value comes back only through the decay of the opposing trace. The F6 savings statistic will therefore rise above 1.0x at a delay, but all of it is recovery, none is faster relearning (section 4 separates the two). A rule by which reinforcement erodes the opposing trace would be a second mechanism (3.1 (m5)); it is not H12 as queued.

### 2.3 Why no behaving run has exercised extinction (read), and why a value change is hard to see in the adopted agent's behaviour (read, inferred)

- **The module receives an odour code only at a source, and every source reinforces.** The once-per-step learning input is code = the odour code of a source the agent stands at, reinforcement = compartment 1 at the rewarding source and compartment 0 at the punishing one (ph15.py:55-61; the same function in Stage C, ph30.py:238). So on every step with a code there is external reinforcement, the gate is closed (ph8.py:81), and the feedback writes nothing. In World6 (H15 Run 2, Stage C) and in Stage B's off-world training (the neutral odour's 30 unreinforced steps start at valence 0, so the drive is 0; the valued odour's steps are reinforced; ph29.py:92-105) **extinction never fires**. Measured consistently: the gate bench (reward and punishment, gated) keeps 1.000 of peak for 400 steps; Run 2's replay without the gate kept 0.049 of the gated value on the agent's own input (97.5 percent interval [0.046, 0.052]), that is, what the gate prevents is the feedback grinding a value down while it is being reinforced, not extinction by omission.
- **Consequence (inferred, exact):** replacing the adopted module by the parallel site with any decay of the extinction pair changes nothing in any recorded behaving run: its compartments 2 and 3 are never written, and decay of a weight at w0 does nothing. This is identity (I4), section 3.3. A behavioural test of H12 therefore needs a world change: reinforcement withdrawn at a source the agent visits.
- **The read-out expresses value by sign and by rank, and by magnitude only through the gain.** The flee reads the sign of the held odour's value (ph23.py:100); the filter's top set, keep and nav read which present non-negative odour has the highest value (ph23.py:89-92); the gate reads the order of two values (ph23.py:66); only the circuit gain 1 + G x max(v, 0) reads a magnitude (ph23.py:62). Because extinction is self-limiting (2.2), a positive value extinguished toward 0 never falls below a neutral odour's 0 and a negative value extinguished toward 0 never rises above it (**inferred**). So at +1/0, an extinguishing reward memory keeps the valued odour at the top of the filter until it reaches the competitor's value, which it approaches but does not cross; and an avoided punisher is never met at its source again (the flee), so an aversive memory cannot extinguish in behaviour at all (**inferred**; avoidance maintains the memory because the code enters only at the source). A behavioural test of recovery therefore needs a positive competitor whose value lies between the extinguished and the recovered value (section 5), which is outside the adopted scope (+1/+0.5 was never validated for the filter; decision:h23-filter-adopted-within-tested-conditions).

### 2.4 What is on record and what is not

- On record (**measured**): H11's two-by-two and F6 (2.2); the gate bench trajectories (ungated: +0.935 at 10 steps, +0.003 at 400; gated: 1.000 throughout); Run 2's replay 0.049 [0.046, 0.052] of the gated value on 389 rewarded rows (stratum 10-24 steps: 0.048), speaking for short stays only; the H15 Run 2 trace interference (+-2.0 against +-0.5 without the 50-step gap); Stage B's saturated learned value (+1.0) and neutral residuals (+7e-6, +0.1000064, +0.2000057, +0.3000050 by shared code units); Stage C's end values (punished -0.889, rewarded 1.000).
- NOT on record: any extinction of a learned value in a behaving agent (2.3: none can occur in the recorded worlds); any value trajectory under reinforcement withdrawal; any retention interval at the module level (H11 ran none: 'no test of spontaneous recovery over time, which this model cannot show since it has no time-dependent forgetting at all'); any decay constant; any behavioural expression of a value between the extinguished and the acquired level.

## 3. The change

### 3.1 The candidates, evaluated from the code and the record

**Where to test (the three candidates the item names):**
- **(a) A module-level test only.** H11's protocols re-run first (bitwise), then acquisition, extinction, a retention interval and a re-test, with the gate alone against the parallel site with decay; no behaving agent. For: cheap, deterministic, fixes the decay constant against the Phase 4 battery before any agent sees it, and would stop the item if the battery cannot be kept (4.2). Against: its main reading is close to true by construction (2.2: spontaneous recovery in the parallel layout with decay is arithmetic), which is exactly the Phase 7.2 lesson (F3 read weights and passed by construction). Alone it cannot earn the parallel site its place (standing rule, Phase 7.2 close: a criterion standing in for a behavioural claim must be behavioural).
- **(b) A behavioural test only**, in Agent17 with learning on, reward withdrawn after tracking and later reinstated. For: the only kind of evidence that could adopt the site. Against: 2.3 shows that in the recorded worlds the two modules are identical by code, that with the reward withdrawn both extinguish identically while the odour is met (decay is the only difference and acts between encounters), and that the adopted read-out shows a value change only at a crossing; without a module bench the decay constant would be chosen blind, and the Phase 4 battery could be broken by it without anyone seeing (4.2 shows the constraint is real: roughly tau_ext >= 5000 steps).
- **(c) Both, in order: the module bench gates the behavioural stage. RECOMMENDED.** Stage 1 (section 4) fixes tau_ext by a registered rule and stops the item if the battery or the recovery fails; Stage 2 (sections 5-7) is outlined now with its world, arms and measures, and its bars are fixed only after Stage 1 and a supplied-value readability check, by a bar decision in the H26 pattern (decision:h26-t2-dwell-bar). A change to the learning module is a change to an adopted module (Phase 4, H8 v2, amended by the Phase 7.2 gate): Stage 1 adopts nothing (a new class in a new file, section 3.2); Stage 2 composes the H12 module into Agent17, which is a composition the owner signs before Stage 2's code (3.4); any adoption is a separate decision after a verdict. Nothing about the module changes silently.

**What 'persist differently' is made of (the mechanism):**
- **(m1) Site-specific decay of the extinction pair. RECOMMENDED.** Parallel site on (ph8.py:85-87), gate on, and after each weight update w[:, c, :] <- w[:, c, :] + (w0 - w[:, c, :]) / tau_ext for c in {2, 3}; compartments 0 and 1 unchanged (no decay, as adopted). One constant. Inert wherever the extinction pair is at w0 (every recorded behaving run, 2.3).
- (m2) Decay of both sites, the extinction pair faster (tau_ext < tau_acq finite). Rejected for now: it changes every learned value in the recorded worlds between visits (Stage B's frozen read-out aside, Stage C's learned values would fade between visits), so it is not inert where the adopted agent is adopted, and it needs a second constant with no anchor.
- (m3) Single site, per-compartment rates (S2 in 2.2). Rejected by arithmetic: recovery for one sign only, the other sign's acquisition transient and its extinguished memory inverting.
- (m4) Single site, one rate for all (S1 in 2.2). Rejected by arithmetic: no recovery at all. Kept as a bench arm (it is the 'forgetting' account against which recovery is read).
- (m5) Reinforcement that erodes the opposing trace (reacquisition by re-pairing). Not H12 as queued: a second mechanism, no anchor on record; it is the natural follow-on if Stage 1 shows recovery without reacquisition (2.2, last point).
- (m6) Context-dependent extinction (renewal). Excluded: the module has no context input.

## 4. Mechanism bench (Stage 1; module only; no agent)

### 4.1 Protocols

- **(r) Reproduction first:** H11's two-by-two and F6 on H11's seeds (I3). Any mismatch stops the bench (an implementation error, fixed before anything is read).
- **(i) Identities** (I1), (I2), (I2'), (I4).
- **(b) The Phase 4 battery F1 and the sustained-exposure probe F2** (ph8.py:112-155, unchanged) for each arm and each tau in the grid.
- **(s) Retention schedules**, per valence sign (punishment on compartment 0; reward on compartment 1), odour codes from the bench seeds: acquisition (10 forward pairings), extinction (20 unreinforced forward presentations), retention D silent steps (mb.step() with no input) for D in {0, 300, 1000, 3000, 5000, 10000}, then read the valence (no step), then one forward re-pairing and read again. ### 4.2 Measures (per sign, medians over runs with 95 percent bootstrap intervals, bootstrap 20261153, 5000 resamples)

- **SR(D)**, the fraction of the extinguished amount recovered at the acquisition site's own scale: (|v(D)| - |v_ext|) / (|a| - |v_ext|), v the behavioural valence, a the acquisition-site valence (MB4.acq_valence, ph8.py:67-69) at the end of extinction. For P it is 1 - (1 - 1/tau)^D exactly (**inferred**: in silence nothing is written, ph4.py:46-60 with a zero code and zero reinforcement, and only the extinction pair relaxes). For A0 and A1 it is 0 exactly; for S1 it is negative.
- **RET(D)**, retention without extinction: |v(D)| / |v_trained|. For P, at least 1.0 (**inferred**: the acquisition pair does not decay, and the part of the opposing trace written during training's code steps decays, so |v| grows toward |a|); for S1, (1 - 1/tau)^D.
- **REACQ(D)**, the re-pairing's own effect: |v after the re-pairing| - |v(D)|. Predicted near 0 or slightly negative in every arm (2.2: the floor, and the re-pairing's code steps write extinction). Reported, no bar.
- **F6(D)**, H11's statistic (|v after the re-pairing - v_ext| / |naive one pairing|), reported for continuity with the queued concept's test ('savings above 1.0x'), with the statement that at D > 0 it is recovery, not relearning.

### 4.5 Predictions at the bench, with the arithmetic (inferred)

- **F1's extinction clause constrains tau_ext.** Per unreinforced presentation the 5 code steps each shrink the expressed valence by the factor 1 - eta_d x beta = 0.985 (tc_now 1 on the active units, ph4.py:54; feedback beta x |v|), so 0.985^5 = 0.9272 per trial and 0.9272^20 = 0.220 after 20 trials: this reproduces H11's 22 percent without decay, a check on the arithmetic. With decay of the extinction pair at rate r = 35/tau per trial, the expressed magnitude x (as a share of the acquisition scale 0.997) follows x' = x (1 - 0.0728 - r) + r x 0.997 from x0 = 0.727; after 20 trials x is about 0.274 at tau 2000 (37.6 percent of trained: F1 FAIL), 0.208 at 5000 (28.7 percent: PASS, a margin of 1.3 points), 0.185 at 10000 (25.5 percent: PASS), about 0.172 at 20000 (about 24 percent: PASS). Approximations: the per-trial decay treated as continuous; the trained value taken as H11's 0.727, whereas decay during training makes it slightly larger, which lowers the percentage (favourable). **Predicted tau_ext* = 5000; 10000 if the 1.3-point margin at 5000 does not hold.** F2 unaffected (the gated feedback writes nothing under sustained reinforcement, so the extinction pair stays at w0; exact).
