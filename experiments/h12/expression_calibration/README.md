All 400 assigned rows were included. Thus the registered task-readability gate passed. At D=5000, V-majority was 0.1725 without decay and 0.8825 with decay, paired difference 0.7100 (95% interval 0.6625–0.7550). This is **calibration**, not held-out evaluation or an H12 adoption decision. Eight acquisition components were negative, seven V values worsened under decay, and all such rows remain in the denominator.
