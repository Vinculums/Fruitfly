== Why B2 fails: sustained pairing erases what it just taught (module in isolation) ==
   The Phase 4 rule carries an opponent feedback (beta 0.15, the MBON-to-DAN loop)
   that pulls an active memory back toward balance. Pairing in bursts and then
   leaving the odour is the case Phase 4 tested. Sitting inside the odour is not.
   reward (compartment 1)     t=5:+0.485  t=10:+0.935  t=25:+0.745  t=50:+0.511  t=100:+0.240  t=200:+0.053  t=400:+0.003
   punishment (compartment 0) t=5:-0.485  t=10:-0.935  t=25:-0.745  t=50:-0.511  t=100:-0.240  t=200:-0.053  t=400:-0.003
   The valence rises, then is ground back to zero as the feedback depresses the
   opposing compartment too. A memory survives only for a stimulus the agent LEAVES.
   In Run 1 the punishing odour was left (so -0.296 stuck) and in Run 2 the rewarding
   odour is sat on (so it does not). That is a property of the Phase 4 rule meeting a
   behaving agent, not of the Phase 5 action rule.
