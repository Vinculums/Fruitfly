## 3. The change, three variants (the owner chooses one before FINAL)

**Common rule.** h = the odour held after this step's selection; v_k the read-out; whiffs this step. present_k is defined per variant, and a held odour always counts as present (present_h = True): without that, a held valued odour after 40 silent steps would leave v_max = 0 and turn the neutral whiff into a surge while the valued odour is held. Then

  v_max = max of v_k over present k; top_k = present_k and v_k >= 0 and v_k = v_max
  nav = hit                             if h >= 0 and (v_h = v_max or v_h < 0)
  nav = any whiff of an odour k with top_k   otherwise
  no odour present (then no whiff this step and nothing held): nav False, the same as Agent6's line.

Nothing else changes (gain, gate, circuit, releases, silence timer on hit, flee, cast, ring). The rule draws no random numbers.

| | (v-a) strict | (v-c) presence counter, starts OFF | (v-p) presence counter, starts ON |
|---|---|---|---|
| present_k | P_k > theta (upstream state the agent already has) | c_k <= N - 1, c_k = steps since odour k was last sensed (0 on a whiff step); c_k = infinity at step 0 | the same counter with c_k = 0 at step -1 (every odour in the repertoire presumed present at the start) |
| new state | none | one counter per odour | one counter per odour |
| classification rule | within it as written | **needs the signed relaxation below** | **needs the relaxation, and contradicts option (v)'s wording for the first N steps** (a never-sensed odour suppresses the surge until N steps pass); it equals the absent-odour report's candidate (ii) |
| effective window | theta 1e-3: 9 to 10 steps; 1e-6: 19 to 20; the window is set by theta alone (P never reaches 0 in a run) | N (exact) | N (exact), and steps 0 to N-2 at the start |
| proposed parameter | theta 1e-3 (the two thetas give the same T1 bounds; 1e-3 is closer to the scale of anything downstream) | N 60 (no N meets the brief's 0.95-of-actions rule; the T1 bounds do not depend on N; 60 for parity with (v-p)) | **N 60**: the plateau of the dev P(V) lower bound is N 45 to 80 at 0.915; 60 is its middle and 1.5 x RESET_AFTER. The brief's rule (keep 0.95 of the filter's actions) gives N 428, which makes the agent Agent8 in W1 for 427 steps |
| T1 prediction | P(V) 0.63 to 0.82 | P(V) 0.63 to 0.82 | P(V) 0.91 to 0.97 |
| T2 (W1) | bitwise Agent6 | bitwise Agent6 | Agent8 for 59 steps, then Agent6's rule from the first B whiff (dev median step 128) |

A leaky trace e_k <- e_k (1 - 1/N) + whiff_k with a threshold realises a window that depends on how many whiffs arrived; the counter realises exactly N with the same state size, so the counter is proposed. The upstream P of (v-a) is itself such a leaky trace (factor 1/2).

**Draft relaxation decision (for (v-c) or (v-p); the owner signs or refuses; precedent decision:h14-adopt-tau1, where a rule was restated by a signed decision naming old, new and anchor).**

> decision:classification-rule-presence-counter (DRAFT, not signed). **Old rule** (owner, H20 Stage A close; H21 design section 3): "The rule uses the agent's own value read-out and its own hold state; no source or axis position, no sensory history beyond what the circuit already holds." **New rule:** "The rule uses the agent's own value read-out, its own hold state, and one presence counter per odour (steps since that odour was last sensed, compared with one fixed window N); no source or axis position, and no other sensory history." **Anchor:** the agent already carries one such counter: `silence` (ph11, the hold's timeout, RESET_AFTER = 40 steps without a hit of the held odour), adopted since Phase 5 Run 2. The new counter is the same kind of state, kept for every odour instead of only the held one, with a window of the same order (N 60 = 1.5 x RESET_AFTER). The window is anchored to the measured task, not to the fly: on the H23 development seeds the scoped agent's P(V) lower bound reaches its plateau at N 45 (ph21b_diag.txt, section 5). No fly finding on odour-presence persistence has been cited by the project; none is claimed. Scope: H24 only, until H24 closes; any later use needs its own decision.

For (v-p) the decision would also have to record that the counter starts ON, i.e. that for the first N steps an odour never sensed is treated as present; this is a prior, not evidence, and it reverses option (v)'s stated premise for that stretch.
