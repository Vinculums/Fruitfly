Status: **v1 FINAL (confirmed by the owner 2026-09-23 as written).** Follows decision:h23-closed (H23 shown under its registered criteria), decision:h23-filter-adopted-within-tested-conditions (the value filter adopted within the tested conditions; this world named as not validated) and decision:next-absent-odour-check-then-stage-b (owner, 2026-09-23, '2. 추천안 진행': this check first, then H20 Stage B). **A check, not a hypothesis**, like the selection-to-navigation link check (design doc d824732220256254b): it measures a cost the adoption already names. ## 1. Question

What does the adopted agent, Agent8 (ph21.py: ph19.Agent6 + the value filter, G 2, the H21 gate on), do in a world that contains only an odour that is NOT top-valued in its value read-out?

**What the code fixes in advance (ph21.py, Agent8.act).** v = chan_valence() (the supplied `known` array), vmax = v.max(1), top = (v >= 0) & (v == vmax), keep = (h >= 0) & ((vh == vmax) | (vh < 0)), nav = np.where(keep, hit, (whiffs & top).any(1)). With the read-out +1 (odour A) / 0 (odour B) and only B's plume present: top is A alone, and A never whiffs; with nothing held nav = (whiffs & top).any(1) = False; with B held vh = 0 < vmax = 1, so keep is False and nav = False again; A cannot be held without A input (checked, section 5 R0). **So nav is False on every (row, step):** the cast clock is since = t + 1, the target is the return cast (tgt = UPWIND + side x off) on every step, and no whiff and no circuit state reaches the movement command. The circuit still receives B (gain 1 + 2 max(0, 0) = 1; nothing is gated while nothing or B is held), so B can be held, and the silence timer counts B's whiffs (hit). This part is certain by code; the self-check verifies it.

**What the code does not fix, and the check measures:** what casting alone does in this world: whether and when the agent comes within 3.0 of the source, how long it stays there, where it drifts, and whether it meets a wall.

**Arithmetic on the cast (an order of magnitude, not a prediction with a bar).** off = MAXOFF (1 - |(since / SAT) mod 2 - 1|) with MAXOFF 170 and SAT = MAXOFF / CAST_GROW = 141.7 (ph9.py, ph12.py): a triangle wave from 0 to 170 degrees and back, period 283.4 steps; the side flips every CAST_PERIOD = 30 steps, which changes the crosswind sign and not the upwind component. If the heading followed the target exactly, the upwind velocity component would average SPEED x mean cos(off) = 0.6 x sin(170 deg) / (170 deg in radians) = 0.6 x 0.1736 / 2.967 = **+0.035 per step, toward the source**: about 21 units in 600 steps and 63 in 1800, with a crosswind swing of up to 0.6 x 30 = 18 units per half-cycle near off 90. Turning is limited (0.6 x the heading error, clipped at 40 degrees, noise 6 degrees) and the heading is the ring's estimate, so this is not a rate to predict from. **Correction to the premise given for this design:** the adopted return cast does not drift downwind on average; by this arithmetic it drifts slowly upwind (the Phase 7.3 saturating cast, superseded at the H16 close, is the one that heads downwind after about 142 steps). So 'never reaches the source' is not implied by the code; reaching it by casting alone is what R1 and R5 measure.

## 2. Why now: the adopted filter's cost

The value filter is relative: it acts on the highest value in the agent's read-out, including the value of an odour the agent is not smelling (design v2 FINAL doc db6df2e0013ab96e7, section 3, 'Classification'). Design v2 section 11, the H23 report (doc d8b91235798da849f, section 7) and the adoption (decision:h23-filter-adopted-within-tested-conditions) all name the same untested case: a world where the higher-valued odour is absent, in which the agent would never surge on the odour present. H23 never met it: in the H21 task both plumes are always present.

Reading, not a measurement: H20 Stage B makes values learned. With learned values ties are measure-zero, so the read-out has exactly one top-valued odour, and every world or stretch of time in which that odour's plume does not reach the agent is, for Agent8, this check's world. The size of the cost therefore bears on the rule's scope before Stage B, which is why the owner placed the check first.

## 3. World, start, worlds, arms

**World.** ph16.World7 unchanged (the H20 Run 2 / H21 / H23 task world: two sources SEP 10 apart crosswind at one downwind coordinate, the 160 x 160 translated arena with walls at least 68 units from either source, the plume model used since Phase 7.3: a whiff from source k with probability 0.30 exp(-d_along / 12) inside the cone 0 < d_along < 25, |d_cross| < 1.5 + 0.25 d_along, and within 3.0 of the source; speed 0.6; a source is reached within HIT_R 3.0; wind sensed every step) with **one source silenced**: a subclass defined in the check's new file whose sense() calls World7.sense() and then sets the absent source's column to False (and recomputes `plume`). World2.sense draws a uniform number for both columns on every step, so masking after the draw consumes the random stream exactly as the task world does on the same seeds. The absent source keeps a location and emits nothing; nothing is measured there. Why not a single-source world class: ph12.World1 / ph12b.World3 (H16) carry one channel and Agent8 reads two; ph11.World2 is itself a two-source world; masking World7 is the smallest change and keeps every other quantity of the H23 task.

**Start.** World7's own start, unchanged: on the midline DOWN = 20 downwind of the sources, heading World7's uniform draw, nothing held, fresh circuit, the per-row initial cast side drawn with the agent seed + 20000 (decision:h20-amendment-initial-cast-side). Relative to the present source: 20 downwind and 5 crosswind, inside its cone (half-width 1.5 + 0.25 x 20 = 6.5), whiff probability 0.30 exp(-20/12) = 0.057 per step, distance 20.6. Chosen so that the only change from the H23 task world is the silenced plume. World7's 2 x 2 cells balance which odour code carries the value and on which side the valued source sits (100 rows per cell); the present source is therefore on +y in half the rows.

**Worlds (A = the odour code carrying the higher read-out value, B = the other; in World7 terms A = `good`):**

| world | present | read-out A / B | role |
|---|---|---|---|
| W1 | B only | +1 / 0 | the cost case: the present odour is not top-valued |
| W2 | A only | +1 / 0 | control: the only odour present is top-valued; the filter is inert |
| W3 | B only | 0 / 0 | identity: the neutral-valence condition under which surge-and-cast and H19 (a) were adopted |
| W4 | B only | -1 / 0 | reported: B is top-valued (v_max 0), the filter is inert |

**Arms, per world, on the same seeds and draws:** Agent8 (filt True: the adopted agent) and Agent6 (Agent8 with filt False, bitwise ph19.Agent6 by H23 bench a1). G 2 and the gate on in both. Learning off; values supplied through `known`.

**What the identities imply (by reading the code; verified in R0).** In W1, W3 and W4, and for Agent6 also in W1, navigation is 'a whiff of the present plume' in every hold state: with B held, nav = hit = B's whiffs; with nothing held, H19 (a) admits B's whiffs (v_B = 0 >= 0), and in W3 / W4 B is top-valued for Agent8 as well. Agent6 in W1 equals Agent6 in W3 bitwise: v_A enters the gain on A's response, which is exactly 0 without A input (ph2.Upstream: the low-passed drive P_A stays 0, so y_A = 0 and 0 x 3 = 0); it enters the gate only as a higher value (A is never gated while B is held) and A is never held; Agent6's nav tests v >= 0 in both. W4 equals W3 bitwise for both agents: the gain on A is 1 + 2 max(-1, 0) = 1 on a zero response, a negative odour is never gated, the flee needs A held, and for Agent8 v_max = 0 makes B top. W2 is the mirror case: nav = A's whiffs in every state for both agents. So the check compares two navigation laws in one world: **'follow the present plume'** (every arm except Agent8 in W1) and **'never surge'** (Agent8 in W1). 'Follow the present plume' is also the known-answer arm's law (ph17.Agent5, held odour fixed; design v2 section 3), which ignores the other plume, so the H23 known-answer arm is a direct reference for it: equal in distribution, not bitwise (Agent5 does not step the circuit, whose noise uses the same agent generator).

## 4. What is recorded

Per row: the first step within 3.0 of the present source; dwell (steps within 3.0) over the horizon; nav steps; whiffs of the present plume, and the first whiff's step; first hold (odour, step), the odour held at the last step, hold endings by flag; steps inside the present cone; downwind distance d_along and crosswind distance to the present source at the last step, and the minimum distance over the run; rows with no whiff of the present plume in the last third ('lost', as in H21 to H23 M6 (a)); rows with no nav in the last third; wall contacts per row; the cast clock maximum. For R5 the same over 1800 steps, reported at 600, 1200 and 1800.

## 6. What this check does not do

It does not test a fix, and it does not re-judge H23 or the adoption. Candidate fixes, listed for the owner's later decision, not chosen, each with its cost against the owner's classification rule (H20 Stage A close; decision:h22-open-design (a) and decision:h23-open-design: the agent uses only its own value read-out and hold state, no source or axis position, no privileged sensory history):

- (i) 'Top-valued among the odours sensed within the last N steps': adds a sensory-history term (which odours were smelled recently); excluded by the classification rule as it stands.
- (ii) 'Surge on any non-negative odour when no top-valued odour has been sensed for N steps': the same sensory-history term.
- (iii) An absolute rule (surge on v >= 0) with the relative filter applied only when a top-valued whiff was sensed recently: the same term.
- (iv) Accept the cost and scope the adoption to worlds where the top-valued odour is present.

It does not test: two positive unequal values (+1 / +0.5); learned values; other G; other geometries; a two-source world in which the top-valued odour's plume exists but does not reach the agent (for the agent the same state as W1; the check does not separate them); the timeout; any change to the circuit or to the cast.
